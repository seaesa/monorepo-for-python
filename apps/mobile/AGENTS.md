# apps/mobile — Expo SDK 58 + Expo Router + Uniwind (Tailwind v4) + React Native Reusables

Read the root `AGENTS.md` first. This app is **UI + platform wiring only**: data fetching, auth
and form schemas come from `@workspace/core`; API types from `@workspace/api-client`.

## Expo has changed — do not trust your training data

Expo ships breaking changes every SDK release. Before writing code that touches an Expo, EAS or
React Native API:

1. Check the `expo` major version in `package.json` (currently 58).
2. Read the matching docs: `https://docs.expo.dev/versions/v58.0.0/`, or start from https://docs.expo.dev/llms.txt (append `.md` to any docs URL).

## Layout

```
src/
  app/                       Expo Router routes only (every file is a screen)
    _layout.tsx              setupApp, fonts, splash, Uniwind theme, Stack.Protected guards, PortalHost
    (auth)/                  login, register (guest-only; index redirects to /login) — same paths as web
    (app)/                   NativeTabs: index (todos), profile (signed-in only)
  features/<feature>/components/   feature UI: auth, todos, preferences
  components/ui/             React Native Reusables components (CLI-managed, aligned to maia)
  components/form/           FormInput, FormRootError (RHF bindings, translated errors)
  components/providers.tsx   QueryClientProvider + AppState focus wiring
  lib/                       setup.ts (setupCore), env.ts, storage.ts (SecureStore), fonts.ts,
                             theme.ts (NAV_THEME from shared hexColors), utils.ts (cn)
  hooks/                     mobile-only hooks (e.g. useRefreshOnFocus)
  global.css                 Tailwind/Uniwind entry; imports @workspace/theme/native.css — no tokens here
  uniwind-types.d.ts         generated by Metro (do not edit)
```

## Rules

- Navigation: Expo Router only. Auth gating is done with `Stack.Protected` in `src/app/_layout.tsx` based on `useAuthStore`; do not add manual redirects in screens.
- Data: hooks from `@workspace/core/<feature>`. Missing hook → add it to `packages/core`. Never call `axios`/`fetch` directly for the backend. Lists use `FlatList` + `RefreshControl`; call `useRefreshOnFocus(refetch)` on tab screens.
- Forms: `useZodForm(schema)` + `FormInput` + `FormRootError`; wire submit as `onPress={() => onSubmit()}` and errors via `applyServerErrors`.
- UI: React Native Reusables (`npx @react-native-reusables/cli@latest add <name>`), never hand-copied. Answer **No** to overwrite prompts. Text must be wrapped in `<Text>` from `@/components/ui/text`.
- **After adding an RNR component, align it** (typecheck points at the first two):
  1. Icons: RNR ships `lucide-react-native`; replace with the Hugeicons icon the web version uses (`<Icon icon={Cancel01Icon} />`, from `@hugeicons/core-free-icons`). Lucide is not installed.
  2. Shape/size: copy the maia classes from the same component in `apps/web/src/components/ui` (e.g. `rounded-4xl`, `h-9`, flat variants, same size/variant names). Drop DOM-only selectors (`has-*`, `aria-*`, `group/*`) or keep them inside `Platform.select({ web })`.
  3. Run `pnpm theme` (root) — the CLI must not have written tokens into `global.css`.
- Styling: Uniwind = Tailwind **v4** syntax, same utilities and tokens as web. Color props on native components use the `accent-` prefix (`placeholderTextColorClassName="accent-muted-foreground"`).
- Fonts: one family (`fontFamily.sans` from `@workspace/theme`) with real weights loaded in `lib/fonts.ts`; `font-medium`/`font-semibold` work as on web. `Text` and `Input` apply `font-sans`.
- Text: `useTranslation()` from `@workspace/i18n`; never hard-code strings. Theme/language: `usePreferencesStore` (root layout forwards theme to `Uniwind.setTheme`).
- Tokens are stored in SecureStore (`src/lib/storage.ts`); never use AsyncStorage for secrets.
- API URL: `EXPO_PUBLIC_API_URL` (origin only). In dev it defaults to the Metro host on port 8000, so physical devices on the same network work.
- `ios/` and `android/` are generated (CNG). Never create or edit them; configure via `app.json` and config plugins.

## Commands (from `apps/mobile`)

```bash
npx expo install <package>   # ALWAYS for native/Expo deps (SDK-compatible versions)
pnpm dev                     # expo start (press i / a / w)
pnpm lint && pnpm typecheck
pnpm doctor                  # expo-doctor: dependency/config health
npx expo export -p ios -p android   # verify bundling without a device
```

After adding a library with native code, a development build is needed (`npx expo run:ios|android` or `eas build --profile development`); Expo Go only has bundled modules.
