# mobile

Expo SDK 58 app (Expo Router, NativeWind v4, React Native Reusables). See [AGENTS.md](./AGENTS.md).

```bash
pnpm dev        # from this folder, or `pnpm dev:mobile` from the root (also starts the API)
```

The API URL defaults to `http://<metro-host>:8000`; set `EXPO_PUBLIC_API_URL` to override.
